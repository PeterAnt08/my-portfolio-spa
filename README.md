# My Portfolio SPA

Це навчальний SPA-проєкт на React, який презентує мене як особистість і початківця-розробника.

## Сторінки проєкту

- `/about` — інформація про мене, мої цінності, навчання та проєкти.
- `/my-city` — інформація про моє місто та поточна погода через API.
- `/my-future` — мої плани розвитку, кроки в майбутнє та робота мрії.

## Технології

- React
- React Router
- JavaScript
- HTML
- CSS
- useState
- useEffect
- fetch API
- localStorage

## API

У проєкті використано API погоди Open-Meteo.

Дані отримуються через `fetch` у `useEffect` та зберігаються у `useState`.

На сторінці `/my-city` виводяться:

- назва міста;
- країна;
- температура;
- опис погоди;
- координати.

## Функціонал

- SPA без перезавантаження сторінок;
- навігація між сторінками;
- отримання даних з API;
- темна та світла тема;
- збереження теми у localStorage;
- адаптивна верстка.
